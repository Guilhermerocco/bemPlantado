## O que é
Projeto Integrador (SENAI, ciência de dados): sistema para **acompanhar plantas** (público: senhoras). Avisa **quando regar**, mostra a **previsão de 7 dias** e as leituras do sensor (caixinha IoT). Requisitos do professor: `Diretrizes_Projeto_Integrador_Monitoramento_Ambiental.docx` (MQTT → banco → API → dashboard + integração externa; campos exatos `temperature, pressure, altitude, humidity, CO2, particula1, particula2, registro_tempo`).

## Arquitetura (pasta deste projeto)
- `app.py` — API Flask + serve o dashboard (`static/`). Rotas listadas no `README.md`.
- `models.py` — tabelas `registro` (campos do professor), `planta`, `rega`, `configuracao`.
- `ingestao.py` — recebe/valida/grava leituras (MQTT). `mqtt.py` é o arquivo original do professor, só referência.
- `fontes.py` — **fonte de dados trocável** por `FONTE_DADOS` no `.env`: `simulada` (padrão, dados fictícios), `mqtt` (caixinha real), `nenhuma`. Na Vercel a simulada roda "sob demanda" (sem thread). Ao trocar simulada → mqtt, apaga as leituras fictícias (plantas ficam).
- `recomendacao.py` — regra de rega (intervalo do **grupo** da planta ajustado por calor, frio, ar seco e chuva prevista). A caixinha mede umidade do **ar**, não da terra.
- `grupos.py` — **base do sistema: 15 grupos de plantas** (tabela do usuário, `tabela_grupos_plantas_nomes_populares.docx`) com textos, nomes populares de exemplo e valores de referência numéricos (rega, temperatura, umidade; **aproximados, a validar pela equipe**). Cada planta cadastrada guarda um `grupo_id`. `texto.py` tem a busca sem acento. `especies.py` (31 espécies) foi **removido**.
- `servicos.py` — Pl@ntNet (foto; **desligado na tela**), Trefle (só referência botânica extra, não define rega), Open-Meteo (previsão, sem chave).
- `DOCUMENTACAO.md` — documentação do projeto (Objetivo, APIs, Público-alvo, Parte da escola, Modelagem do banco). Aguardando o restante do roteiro do usuário e o formato final (Word/PDF).
- `static/` — dashboard: `index.html`, `styles.css`, `app.js`.
- `simulador.py` — opcional, publica leituras fictícias pelo MQTT (testar o caminho MQTT).
